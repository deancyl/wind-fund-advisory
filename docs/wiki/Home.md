## v2.0.0 核心里程碑
- **现代前后端解耦**：React 19 + TypeScript + Tailwind CSS + ECharts 前端，FastAPI 单端口（`127.0.0.1:8000`）一体化托管。
- **目标驱动闭环**：支持设定「目标持有周期 × 目标收益率」，基于 8 年真实历史净值跑滚动达标概率，并利用基金详情真数据做多因子量化评分与权重倾斜。
- **10 维度基金详情工作台**：全站任意基金一键点击查看走势/净值图、历史业绩、自定义定投测算、4 大类 8 小类量化指标、持仓分布、历任基金经理、档案/公告/交易规则。
- **隐私脱敏与本地安全**：公开仓库不含任何个人持仓数据，所有写入账本操作前自动生成不可变冷备快照。
