# 目标收益 × 多因子量化选基与调仓引擎

## 1. 两步分工（风险档位 vs 配置模型）
- **第一步 · C1~C5 风险档位**：决定组合的总股债仓位上限与回撤预算；
- **第二步 · 4 套量化配置模型**：在既定风险预算内决定资产风格与配权逻辑：
  1. **全天候动态均衡模型（全档位适配）**：结合十维宏观信号与波动率缩放，跨周期均衡配置红利、宽基、纯债、海外与黄金。
  2. **风险平价抗跌模型（推荐 C1~C3）**：按各资产近 60 日真实波动率倒数分配风险预算，严控组合回撤。
  3. **高股息红利防御模型（推荐 C1~C3）**：重点倾斜红利低波、红利增强与纯债底仓，适合利率下行与震荡筑底阶段。
  4. **杠铃攻守策略模型（推荐 C3~C5）**：纯债黄金守底线 + 科创50/纳指100高弹性进攻。

## 2. 目标时间区间 × 目标收益率滚动验证 (`goal_driven_selector.py`)
- 用户设定 **目标持有周期（6/12/24/36 个月）** 与 **目标收益率（%）** 后：
  - 自动换算所需年化收益率，检测是否存在「目标收益 vs 风险承受力」碰撞并给出对齐建议；
  - 在 2018 至今全量真实历史净值上按周滚动切分上百个历史起点，实算 **历史达成概率（%）、中位收益、P05 最差情景与平均达标耗时**；
  - 在调仓参考页同步对比「调仓前当前持仓」与「调仓后目标组合」的达标概率与底线改善。

## 3. 基金详情多因子评分反哺选基
- 并发采集候选基金的真实详情指标（夏普比率、卡玛比率、最大回撤、年化波动率、净值新高率、超额收益、信息比率、跟踪误差、规模、费率、经理稳定性）；
- 按目标年化收益动态调整因子权重，输出 **0~100 多因子量化综合得分** 并对模型基础权重实施 `±15%` 温和倾斜（严格保证权重和 `= 100.0%` 与精确只数输出）。
