## 一、重构目标与非目标

### 目标（Goals）
1. **一级信息架构彻底重构（4 大互斥工作区 + 统一数据中心）**：
   - `quant_lab`（**量化实验室 · 默认首屏**）：纯量化研究与组合构建沙盒（可折叠 `268px` 左参数台 + 右侧 4 个单屏子视图：`组合矩阵` / `净值与情景回测` / `极端周期与止盈` / `A/B 方案对比`）。
   - `market`（**市场与信号**）：宏观大势定调、十维量化投票矩阵、核心指数/自选观察、场内 ETF 溢价监控、拥挤度四象限全景。
   - `holdings`（**实盘与风控**）：资产总览极简 KPI 带、持仓风险预警、资产缺口 + 申万行业穿透 + 底层重仓重叠、极端压测 CVaR、调仓影子 Alpha 追踪、可排序筛选持仓明细与净值对账表。
   - `rebalance`（**调仓执行**）：平滑低换手 vs 实验室全市场方案一键对齐、目标达标改善对比、三阶执行清单（清尾仓 / C转A / 核心再平衡）、A/C 费率精算器、限购拆单与分红建议、增量新钱 DCA、本地打卡闭环。
   - **彻底移除原 448px 垃圾桶式 `ProAnalysisDrawer`**；账本切换/新建、现金编辑、文本/OCR 导入明细核对、盘后安全日更、冷备快照还原统一收拢至顶栏右上角「**数据与账本中心**」模态框。
2. **视觉设计系统全面净化（消除 AI 模板感与彩虹疲劳）**：
   - 全局外壳：`48px` 极简深海墨蓝顶栏 + `34px` 实盘 Ticker 状态带（宏观定调 + 三大指数 + 本地真净值湖仓状态与安全日更快捷按钮），彻底取消旧首页占 1/3 屏高的大块广告牌英雄区。
   - 色彩铁律：`#F8FAFC` 浅灰底布 + 纯白 `1px solid #E2E8F0` 利落圆角（`rounded-lg`）容器；90% 灰白深墨蓝 + 单一主交互色 `#1D4ED8` + 语义涨红 `#DC2626` / 跌绿 `#059669` / 告警琥珀 `#D97706`；**清零彩虹渐变 KPI 卡、清零 6 色左竖杠、清零黑/黄/蓝三层叠罗汉横幅、清零常驻 `ChartReadingGuide` 新手教学框**。
   - 统一组件语法：全站统一底线式 Underline Sub-Tabs、高密度等宽右对齐金融数据表、`?` 悬浮专业口径审计卡（公式/窗口/样本起止日/假设）。
3. **从“静态报表”进化为“可操控投研终端”**：
   - **单基排除 / 锁定重算**：支持在组合矩阵表与左侧约束区排除或锁定任意基金并重新全市场求解；
   - **A/B 方案对比与投研报告导出**：支持保存最多 4 组方案快照（`localStorage` 持久化，强制绑定 `lakehouse_latest_date` 与双口径指标），支持并排指标/权重 Diff 对比，支持一键导出 Markdown / JSON 投研报告；
   - **右侧无跳页 Fund Inspector 检查器**：点击全站任意基金以 `fixed right-0` 浮层滑出（净值走势、配权推导公式、核心量化指标、十大重仓与限购规则、一键排除/锁定、一键展开全屏完整档案），零布局挤压、零页面状态丢失；
   - **`Ctrl/Cmd + K` 全局命令搜索面板**：复用 `/api/v1/funds/search` 秒搜全市场基金进检查器、切换工作区、切换账本、触发日更或导出报告；
   - **零原生弹窗 + 所见即所写导入核对**：消灭全站全部 `window.prompt / confirm / alert`；粘贴文本与截图 OCR 均先走 `mode="preview"` 渲染可勾选、可编辑金额/删除误识别行的确认表，确认后将干净结构化列表直接写入 `/api/v1/holdings/import`。

### 非目标与绝对红线（Non-Goals & Constraints）
- 暂不开发“小白简洁模式”与“盘中 14:50 实时估值择时提醒”。
- 严格只读保护 4 大裁判文件：`AGY2_FundAdvisory/judge_engine.py`、`AGY2_FundAdvisory/holdout_vault.py`、`AGY2_FundAdvisory/AGENT_SPEC.md`、`tests/test_infra.py`，以及 `DataLoader.simulate_execution` 默认签名与扣费实现。

## 二、7 项红队自查漏洞与工程堵漏规范

| # | 漏洞 | 强制落地的工程堵漏方案 |
|---|---|---|
| 1 | 排除/锁定基金的幽灵复活与数学冲突 | `exclude_codes` / `include_codes` 贯穿 `solve_goal_driven_portfolio`、缓存 Key、`POST /api/v1/quant/solve`、`/recommend/blueprint`、`/charts/backtest_curves`、`/charts/scenario_backtest`、`/rebalance` 全链路；前置校验 C 档大类与只数冲突并返回结构化 `constraint_warnings`；切 `index_only` 时自动剥离主动基金锁定并明文提示。 |
| 2 | 切 Tab 卸载导致异步求解中断与状态失忆 | 新建 `WorkbenchContext` 顶层状态机承载异步轮询、最新 `blueprint` / `curves`、`appliedParams`、排除/锁定列表、对比快照与侧栏折叠态；已访问页面不丢求解结果且后台轮询不中断。 |
| 3 | A/B 对比跨日湖仓漂移与窗口口径错配 | 快照强绑定 `lakehouse_latest_date`、全套输入参数、权重表与固定双口径指标（近 1 年 + 全周期 + 目标达标率）；当当前湖仓日期晚于快照日期时强制显示「历史快照」标签并提供一键按同参数重算刷新。 |
| 4 | 拥挤度搬迁后实验室缺短线温度 | `_build_blueprint_payload` 直接透传每只入选基金的真实 `bias_20`、`crowding_score`、`ret_20d`、`quadrant_tag`，在实验室组合矩阵表内直接呈现「MA20乖离 / 温度」列；完整四象限散点全景归位至「市场与信号」。 |
| 5 | 窄屏笔记本与 390px 移动端布局崩塌 | Inspector 采用 `fixed right-0` 浮层 + 轻遮罩零挤压；`< 1280px` 实验室自动折叠左参数台为顶部摘要条；`< 768px` 移动端 Ticker 带采用横向无滚动条可滑动布局，严格保障 4 大页面 `0px` 水平溢出。 |
| 6 | 降噪过头隐匿关键风控与数据口径差异 | 明确分层：清理教学与自夸长文；**永不隐藏** 4 类硬提示（参数变更 Stale 条、目标与 C 档冲突条、早期情景基准替代声明、单基限购与 7 天 1.5% 赎回惩罚锁）。 |
| 7 | 导入预览修改后被覆盖（所见非所写） | 文本与 OCR 统一先调 `mode="preview"` 呈现可编辑核对表；确认写入统一调用 `/api/v1/holdings/import` 写入用户最终核对后的列表（合并/覆盖前自动冷备）。 |

## 三、分阶段验证与验收门禁
1. **后端契约与数学公理**：`pytest` 全套测试（含新增排除/锁定全链路闭环、冲突校验与 `bias_20` 透传单测）+ `scripts/verify_readonly_hashes.py` 4 裁判哈希 100% 校验。
2. **前端编译与静态检查**：`web/` 下 `npm run build` 0 TypeScript / CSS 错误，源码全局 `grep` 确认 `window.prompt / window.confirm / window.alert` 计数为 **0**。
3. **真实浏览器三端实机回检**：重启 `127.0.0.1:8000`，使用 Playwright 对 `1440×900`、`1280×800`、`390×844` 三档视口遍历 4 大工作区 + 侧栏折叠 + 排除重算 + A/B 对比 + 右侧 Inspector + 数据中心 + `Ctrl+K` 截图并人工视觉审查，0 控制台报错、0 网络 4xx/5xx、0px 移动端水平溢出。
