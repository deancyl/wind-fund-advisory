## 二、 极速安装与一键启动指南

### 1. 运行环境要求
- Python 3.10+ (已内置 `streamlit`, `plotly`, `pandas`, `duckdb`, `rich`)
- 工作区路径：`d:\Google\Workspace\Wind`

### 2. 本地工作台一键启动
在终端或 PowerShell 中执行以下命令：

```bash
# 1. 切换至项目根目录
cd d:\Google\Workspace\Wind

# 2. 启动 Streamlit 本地图形化工作台
streamlit run app_gui.py
```

终端将输出本地服务访问地址：
```
  Local URL: http://localhost:8501
  Network URL: http://192.168.x.x:8501
```

### 3. Windows 纯静默原生桌面模式（零控制台黑框推荐）
根据工作区桌面准则，项目内置了无黑框后台托管与独立应用级交互唤起脚本：
- **双击运行**：`launch_gui.bat` 或 `wscript.exe launch_gui.vbs`；
- **运行机理**：脚本自动毫秒级探测 8501 端口，若未启动则在 Windows 后台纯静默（`CREATE_NO_WINDOW` / `SW_HIDE`）拉起 Streamlit 服务，随后以 Edge `--app=http://localhost:8501` 独立桌面模式唤起，无地址栏、无标签页，享受媲美原生 Electron 桌面软件的高颜值清爽体验。

## 三、 核心业务模块与交互功能详解 (四大核心工作区)

### 1. 顶部全局看板：真实行情接入与 15:00 申赎生死线 (消灭假数据)
- **申赎交易时钟（15:00 生死线倒计时）**：
  - `09:30 - 14:30 (🔵 盘中观察期)`：实时展示行情观察提示，明确提醒“尾盘 14:30 后再锁定最终操作，防止日内跳水翻车”；
  - `14:30 - 14:55 (🟢 黄金执行窗口)`：大盘趋势与基金估值基本锁定，顶部以高亮绿色徽章显示**距离 15:00 收盘停机的实时倒计时（分:秒）**，锁定当日 $T$ 日净值成交；
  - `14:55 - 15:00 (🔴 临界关账窗口)`：提示极速提交，防止网关拥堵；
  - `15:00 之后及非交易日 (🟡 延时窗口)`：明确提示“当前下单将按下一交易日（$T+1$）收盘净值成交”，彻底消除误把当日净值当成交价的认知偏差。
- **Trial 29 实时状态机**：接入 `strategy_bridge.py` 动态判定：`🟢 常态稳健高股息慢牛` / `🔥 进攻科技成长大牛市` / `📈 结构分化牛市` / `🛡️ 深度大熊市防御`，并显示已持续的交易日数；
- **沪深300趋势生命线**：动态测算点位及相对于 MA20、MA60、MA120 的真实偏离度；
- **真实股债性价比 (ERP) 分位数**：中债 10Y 国债收益率（1.63%）与真实 ERP 历史分位数（>80% 极高性价比），刚性执行 GEMINI 规则——**严禁在底部盲目割肉休克转纯债**；
- **全组合总资产与基准回撤看板**：汇总持仓总市值、可用现金池与在途款，并实时追踪接管基准以来的**绝对收益率、超额收益 (Alpha vs 沪深300) 与历史最大回撤**。

### 4. Tab 3：【💼 我的持仓账本与接管向导】
- **3 步傻瓜式接管向导**：
  - 【方式一：极简冷启动】：仅需录入基金代码与金额，自动以接管当日净值重置基准；
  - 【方式二：Excel/CSV 文件导入】：支持历史明细流水（自动构建 FIFO 批次）与持仓快照覆盖恢复；
  - 【方式三：单只基金追加录入】：零干扰增补新标的，不冲刷已有持仓；
- **持仓明细直接编辑 (`st.data_editor`)**：
  - 双击单元格直接修改份额、净值、成本价与分红方式，一键保存并写入 SQLite；
  - 侧边栏支持 30 层 Undo 一键撤销回滚；
- **FIFO 批次透视与免赎回费倒计时**：
  - 展开查看每只基金的底层 FIFO 份额批次、已持天数及距离满期免惩罚费倒计时；
  - 卖出时自动调用 `get_penalty_free_redeemable_shares` 裁剪份额，坚决保护未满 7 天批次。

## 五、 投顾风控守则与合规红线 (GEMINI Compliance)

本工作台严格内置了 Wind 投顾量化工作区的四大约束红线：
1. **公募基金底层资产绝对穿透准则**：严禁仅凭“红利”、“稳健”等外壳粗暴定性，必须穿透至重仓股与行业分布；
2. **交易摩擦成本、A/C端份额与流动性锁定期红线**：7天惩罚费强拦截、A类180天阶梯保护、C类反弹清理、单日限购拆单；
3. **宏观估值分位与反向踏空防御准则**：在 ERP $> 75\%$ 历史极度低估时，严禁提出割肉休克转纯债的毁灭性建议；
4. **五面合一动态预警与多周期胜率推演**：技术均线系统（MA20/MA60）、负乖离率（Bias）与绿黄红三色分级盯盘。
