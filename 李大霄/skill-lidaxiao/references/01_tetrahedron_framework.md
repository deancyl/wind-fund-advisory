# 李大霄投资四面体模型 (Investment Tetrahedron Framework)

> 出处：《李大霄投资战略》（2025年第3版）核心理论体系

---

## 一、模型图解与核心内涵

李大霄在从事证券行业30余年、历经多轮牛熊沉浮后，在工科电机学建模思维的启发下，提炼出了**“投资四面体”**系统分析模型。

```
                    宏观经济
                  (国运与政策)
                     /  \
                    /    \
                   /  投  \
                  /  资四  \
      市场趋势  ------------  股票质量
    (周期与估值) \  面体  /  (好股 vs 黑五类)
                  \     /
                   \   /
                    \ /
                投资者行为
              (余钱/阶梯/心态)
```

### 四大维度的制约与协同关系：
1. **宏观经济定“有没有饭吃”**：
   - 投资就是投国运。中国经济长期向好的基本盘没有改变。
   - 在中国投资要讲政治，政府和政策具有最终的系统性托底意志。政策暖风频吹时，系统性崩溃风险被封堵。
2. **市场趋势定“什么时候吃”**：
   - 底部不是一个点，而是一个发育区域（从胎盘、婴儿、儿童到少年）。
   - 沪深300 PE在10~15倍区间是历史规律性的大底。
   - 绝大多数人之所以亏损，是因为在底部割肉出场、在顶部亢奋追高；而理性的投资四面体要求在冬天播种、在秋天收获。
3. **股票质量定“吃什么”**：
   - 好股票 = 好公司 + 合理价格。
   - 必须以低估值、高分红、真盈利、大央国企龙头为核心资产；对“黑五类”（小盘、次新、垃圾、题材、伪成长）必须一票否决。
4. **投资者行为定“能不能消化”**：
   - 这是四面体中最容易被忽视、却也是决定生死的一环。
   - 必须用余钱（3-5年以上不用的钱），绝对不加杠杆，坚守散户进阶六阶梯，心态淡定从容。

---

## 二、四大维度的木桶约束机制（一票否决）

四面体各面并非机械相加，而是具有乘数效应与一票否决权：

| 异常情景 | 表现形式 | 四面体诊断与后果 | 大霄忠告 |
|---|---|---|---|
| **好股票 + 差行为** | 借钱加杠杆买低估蓝筹，或者用了3天后要买房的急钱 | 短期剧烈波动直接触发强平爆仓，死在黎明前 | “杠杆借贷小心！余钱才能淡定！” |
| **好大势 + 坏股票** | 牛市或底部反弹期，全仓买入小市值次新题材股 | 潮水退去一地鸡毛，好股票涨了题材股退市了 | “远离黑五类，方能实现幸福美好人生！” |
| **好公司 + 差趋势** | 在5000点地球顶狂热追高60倍PE的所谓“核心资产” | 估值杀跌数年难以回本，付出惨重时间成本 | “好公司买贵了也是灾难，保护胜利果实！” |
| **好宏观 + 坏心态** | 天天盯盘追涨杀跌，听信小道消息频繁换手 | 沦为抬轿者，高额手续费和磨擦成本侵蚀全部本金 | “交易的最高境界是少交易！” |
